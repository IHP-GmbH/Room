Types & enums (Python)

Dataclasses and enums returned by the Python API. Immutable value objects unless noted.

Module helpers

room.sniff(path) → FileInfo

Reads .room header metadata without fully decoding geometry (fast inventory).

room.has_oas() → bool

True if this room_c build includes OASIS import/export.

Enums

View arguments also accept strings: "layout", "schematic", "symbol", "abstract".

Example

info = room.sniff("design.room")
print(info.lib_name, info.cell_count, info.primary_cell)

from room import ViewType, Orient, LayerPurpose
db = room.create()
db.add_layer(1, 0, "Metal1", LayerPurpose.DRAWING)
cell = db.get_or_create_cell("TOP")
layout = cell.ensure_content(ViewType.LAYOUT)
layout.add_instance("INVX1", x=0, y=0, orient=Orient.R90)
