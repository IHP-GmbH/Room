Detailed Description

A room::Block holds shapes, child Instance placements, and schematic Net / Term connectivity for one cell view.

In a .room file (v1.0), blocks are not stored directly on CellContent. They live inside CellContent.payload — for example payload.layout.block or payload.schematic.block (schema/views.capnp). In C++, use CellContent::block() on the parent view; serialization maps between the in-memory block and the payload arm selected by viewType.

const std::vector<Net> & nets() const

Returns electrical nets for read-only access.

Returns: Const reference to the net vector.

const Box & bbox() const

Returns the cached axis-aligned bounding box of this block.

Returns: Bounding box in DBU. Call recomputeBBox() after changing shapes to refresh the value.

void recomputeBBox()

Recalculates the bounding box from all shapes in this block.

Instance placements are not included in the bbox calculation. The result is stored internally and returned by bbox().

Example

room::Block block;

block.shapes().emplace_back(room::Shape::RectData{{0, 0, 500, 300}, 0});
block.instances().emplace_back("INV", room::Transform{2000, 2000, room::Orient::R0});
block.nets().emplace_back("VDD", room::SigType::Power);

block.recomputeBBox();
std::cout << block.bbox().urx << "\n";
