cdb::Block class

src/block.h · #include "block.h"

Topology container: geometry, child cell placements, and nets (for schematic views).

Member functions

std::vector<Shape> & shapes()

Returns geometric shapes in this block for modification.

Returns: Mutable reference to the Shape vector (rectangles, polygons, paths, text).

const std::vector<Shape> & shapes() const

Returns geometric shapes for read-only access.

Returns: Const reference to the shape vector.

std::vector<Instance> & instances()

Returns child cell placements for modification.

Returns: Mutable reference to Instance entries (GDS SREF equivalents).

const std::vector<Instance> & instances() const

Returns child cell placements for read-only access.

Returns: Const reference to the instance vector.

std::vector<Net> & nets()

Returns electrical nets for modification (typically used in schematic views).

Returns: Mutable reference to Net objects.

const std::vector<Net> & nets() const

Returns electrical nets for read-only access.

Returns: Const reference to the net vector.

const Box & bbox() const

Returns the cached axis-aligned bounding box of this block.

Returns: Bounding box in DBU. Call recomputeBBox() after changing shapes to refresh the value.

void recomputeBBox()

Recalculates the bounding box from all shapes in this block.

Instance placements are not included in the bbox calculation. The result is stored internally and returned by bbox().

Example

cdb::Block block;

block.shapes().emplace_back(cdb::Shape::RectData{{0, 0, 500, 300}, 0});
block.instances().emplace_back("INV", cdb::Transform{2000, 2000, cdb::Orient::R0});
block.nets().emplace_back("VDD", cdb::SigType::Power);

block.recomputeBBox();
std::cout << block.bbox().urx << "\n";
