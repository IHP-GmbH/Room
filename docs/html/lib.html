Detailed Description

A core::Lib is a named collection of Cell objects and a shared LayerSpec table. Each Database owns exactly one library (default name "default").

Shapes and terminals store a layerId index into Lib::layers(), not GDS layer numbers directly. Importers such as GdsImporter build this table once per library while scanning the file.

Example

core::Lib lib("my_pdk");
lib.properties().push_back({"author", "team"});
lib.layers().push_back({1, 0, "MET1", core::LayerPurpose::Drawing});
lib.layers().push_back({8, 25, "L8/D25", core::LayerPurpose::Label});

core::Cell & top = lib.getOrCreateCell("TOP");
core::CellContent & layout = top.getOrCreateContent(core::ViewType::Layout);

layout.block().shapes().emplace_back(
    core::Shape::RectData{{0, 0, 1000, 1000}, 0});
