Example: Xschem schematic → CORE → round-trip

The xschem_to_core program — import, save with view suffix, sniff, export

1. Run (command line)

.\build\xschem_to_core.exe examples\xschem_to_core\data\test.sch examples\xschem_to_core\output\test.schematic.core
ArgumentDescription
input.sch|symXschem file (default: examples/xschem_to_core/data/test.sch)
output.coreCORE file — prefer <cell>.schematic.core
roundtrip.outOptional export for verification

2. Sniff without loading geometry

#include "file_summary.h"
core::CoreFileInfo info = core::sniffCoreFile("test.schematic.core");

See file summary API and docs/SNIFF.md.

3. Data flow

Xschem .sch / .sym → XschemImporter (xschem_io) → Database::saveToFile ├─► sniffCoreFile() for LibMan routing └─► XschemExporter → payload/*.sch

4. In-process (Xschem + Tcl)

Build coretcl.so and use xschem_bridge from Tcl.
