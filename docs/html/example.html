Example: GDS → CORE → text dump

The gds_to_core program — layout import workflow

Schematic import from Qucs: Qucs example.

1. Build (VS Code)

Ctrl+Shift+B → choose a task:

TaskOutput
Build: Static Libraries (.a)build/libcore.a, build/libcore_utils.a
Build: All TargetsLibraries + gds_to_core.exe, make_sample_gds.exe
Install: Libraries + Headersinstall/ prefix for other projects
Example: Build & Run Full DemoSample GDS → output/sample.core

2. Build (command line)

cmake -S . -B build -G "MinGW Makefiles"
cmake --build build --target core core_utils

On first cmake configure, Cap'n Proto is built into third_party/capnp-install/ automatically. Sample layout GDS can come from the IHP Open Source PDK (sg13g2) or make_sample_gds.

3. Link from another project

# after: VS Code task "Install: Libraries + Headers"
list(APPEND CMAKE_PREFIX_PATH "C:/path/to/CORE/install")
find_package(CORE REQUIRED)

add_executable(my_app main.cpp)
target_link_libraries(my_app PRIVATE CORE::core_utils)
target_include_directories(my_app PRIVATE ${CORE_INCLUDE_DIRS})
# also link capnp + kj from third_party/capnp-install/lib

4. Sample GDS

.\build\make_sample_gds.exe testdata\sample.gds

Creates a minimal GDS with cells INV and TOP.

5. Import

.\build\gds_to_core.exe testdata\sample.gds output\sample.core output\sample.txt
ArgumentDescription
input.gdsInput GDSII file
output.coreBinary CORE file (Cap'n Proto)
dump.txtText dump (optional; defaults to output.core.txt)

6. Example source

Source file: examples/gds_to_core/main.cpp

#include "database.h"
#include "gds_importer.h"
#include "text_dump.h"

core::GdsImporter importer;
core::Database db = importer.importFile("testdata/sample.gds");

db.saveToFile("output/sample.core");

core::TextDumper dumper;
dumper.dumpToFile(db, "output/sample.txt");

// round-trip check
core::Database reloaded = core::Database::loadFromFile("output/sample.core");

Core headers are under src/ (database.h, …). Utility headers are under utils/ (gds_importer.h, text_dump.h). CMake adds both directories to the include path for linked targets.

7. Data flow

GDS file │ ▼ GdsImporter::importFile() │ STRNAME, BOUNDARY, PATH, SREF, TEXT, UNITS … ▼ Database → Lib → Cell → CellContent(layout).payload.layout.block │ ├─► Database::saveToFile() → sample.core └─► TextDumper::dumpToFile() → sample.txt

8. GDS → CORE mapping

GDS recordCORE

TEXTShape::Text

Limitations

  • AREF is not expanded into geometry
  • Only ViewType::Layout is imported from GDS
  • GDS user properties (PROPATTR/PROPVALUE) map to gds.prop.<attr> on cells, shapes, and instances
