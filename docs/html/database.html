CommonDB » Classes » Database

cdb::Database class

src/database.h · #include "database.h"

Root object of CommonDB. Holds file metadata and one Lib. Serialized to a binary .cdb file via Cap'n Proto.

Member functions

Database()

Default constructor. Creates an empty in-memory database.

Postcondition: version() is "0.1", metadata strings are empty, and lib() is a library named "default" with no cells.

const std::string & version() const

Returns the CommonDB file format version stored in this database.

Returns: Format version string (default "0.1" for a newly constructed database).

void setVersion(std::string value)

Sets the format version written to the file header on save.

ParameterDescription
valueVersion string (for example "0.1").
const std::string & generator() const

Returns the name of the tool or program that created this database.

Returns: Generator name; empty if not set.

void setGenerator(std::string value)

Records which program produced this database (stored in the file metadata).

ParameterDescription
valueTool name (for example "CommonDB GdsImporter" or "MyTool").
const std::string & technology() const

Returns the technology or PDK identifier associated with this design.

Returns: Free-form technology string; empty if not set.

void setTechnology(std::string value)

Associates a technology or PDK name with the database.

ParameterDescription
valueTechnology string (for example "sg13g2").
Lib & lib()

Returns the root cell library for read/write access.

Returns: Reference to the single Lib owned by this database.

const Lib & lib() const

Returns the root cell library for read-only access.

Returns: Const reference to the single Lib owned by this database.

void saveToFile(const std::string & path) const

Serializes this database to a binary Cap'n Proto file.

ParameterDescription
pathOutput file path. The file is created or overwritten. Conventionally uses the .cdb extension.

Throws: std::runtime_error if the file cannot be opened for writing.

static Database loadFromFile(const std::string & path)

Reads a database from a binary Cap'n Proto file previously written by saveToFile().

ParameterDescription
pathInput file path of an existing .cdb file.

Returns: A new Database populated from the file.

Throws: std::runtime_error if the file cannot be read or parsed.

Example

cdb::Database db;
db.setGenerator("MyTool");
db.setTechnology("sg13g2");
db.lib().getOrCreateCell("TOP");

db.saveToFile("design.cdb");

cdb::Database loaded = cdb::Database::loadFromFile("design.cdb");
std::cout << loaded.lib().cells().size() << " cells\n";
