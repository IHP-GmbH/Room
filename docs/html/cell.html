CellContent * findContent(ViewType type)

Looks up view data for a specific view type.

ParameterDescription
typeViewType to search for (Layout, Schematic, Symbol, or Abstract).

Returns: Pointer to the matching content, or nullptr if that view has not been created.

const CellContent * findContent(ViewType type) const

Looks up view data for a specific view type (const overload).

ParameterDescription
typeViewType to search for.

Returns: Const pointer to the matching content, or nullptr if missing.

CellContent & getOrCreateContent(ViewType type, double dbuPerMicron = 1000.0)

Returns existing view data or creates a new CellContent entry.

ParameterDescription
typeView type for the content to retrieve or create.
dbuPerMicronDatabase units per micron. Used only when a new content entry is created; ignored if content for type already exists.

Returns: Reference to the existing or newly created content.

Example

room::Cell cell("NAND2");

room::Lib & lib = db.lib();
lib.layers().push_back({1, 0, "MET1", room::LayerPurpose::Drawing});

// layout view
room::CellContent & lay = cell.getOrCreateContent(room::ViewType::Layout, 1000.0);
lay.block().shapes().emplace_back(room::Shape::PolygonData{
    {{{0,0}, {100,0}, {100,50}}}, 0});

// schematic view (empty for now)
cell.getOrCreateContent(room::ViewType::Schematic);

if (cell.findContent(room::ViewType::Symbol) == nullptr) {
    // symbol view not created yet
}
