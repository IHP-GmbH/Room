What is inside a .room database?

Database # room.Database / room.open(...) +-- metadata # version, generator, technology, lib_name, file_view +-- layers[] # room.Layer (GDS layer/datatype catalog) +-- cells[] # room.Cell +-- contents[] # room.CellContent (one per view) +-- view # layout | schematic | symbol | abstract +-- shapes[] # room.Rect (other shape kinds listed as dict) +-- instances[] # room.Instance (child cell placements) +-- bbox # room.Box

Module functions

room.open(path)Load a .room file → Database.
room.create()Empty in-memory database.
room.from_gds(path)Import GDSII.
room.from_qucs(path)Import Qucs .sch.
room.from_xschem(path)Import Xschem .sch/.sym.
room.from_oas(path)Import OASIS (if has_oas()).
room.sniff(path)Header-only metadata → FileInfo.
room.has_oas()Whether OASIS support is linked.

Typical walk

import room

db = room.open("design.room")
print(db.lib_name, db.version)
for name in db.cell_names():
    cell = db.find_cell(name)
    layout = cell.layout          # or cell.content("schematic")
    if layout is None:
        continue
    print(name, "shapes=", len(layout.shapes), "bbox=", layout.bbox)
    for inst in layout.instances:
        print("  instance of", inst.cell_name, "at", inst.x, inst.y)
