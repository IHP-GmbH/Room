CORE path helpers

Parse and build view-specific <cell>.<view>.core filenames. More…

CMake:target_link_libraries(mytarget PRIVATE CORE::core)

Detailed Description

LibMan, Xschem Tcl (coreapi_parse_core_path), and project files use these helpers. See CORE_FILE_NAMING.md.

struct ParsedCorePath

cellName, view, valid — set when basename matches name.view.core.

Example

auto p = core::parseCoreFilePath("lib/inv.schematic.core");
if (p.valid) { /* p.cellName == "inv", p.view == Schematic */ }
