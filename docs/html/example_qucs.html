Example: Qucs schematic → CORE → round-trip

The qucs_to_core program — schematic import, save, reload, export

1. Run (VS Code)

Tasks: Run Task → Example: Qucs to CORE

2. Run (command line)

.\build\qucs_to_core.exe examples\qucs_to_core\data\rc_lowpass.sch examples\qucs_to_core\output\schematic.core
ArgumentDescription
input.schQucs schematic (default: examples/qucs_to_core/data/rc_lowpass.sch)
output.coreCORE file — any path/name, e.g. schematic.core
dump.txtText dump (optional)
roundtrip.schExported Qucs file after reload (optional)

3. Source code

examples/qucs_to_core/main.cpp

#include "database.h"
#include "qucs_importer.h"
#include "qucs_exporter.h"
#include "text_dump.h"

core::QucsImporter importer;
core::Database db = importer.importFile("rc_lowpass.sch");

db.saveToFile("schematic.core");

core::Database loaded = core::Database::loadFromFile("schematic.core");

core::QucsExporter exporter;
exporter.exportCell(loaded, "rc_lowpass", "schematic_roundtrip.sch");

4. Data flow

Qucs .sch (text) │ ▼ QucsImporter::importFile() │ Components → Instance, Wires → Net/Term ▼ Database → Cell → CellContent(schematic).payload.schematic.block │ ├─► Database::saveToFile() → schematic.core ├─► Database::loadFromFile() → reload check └─► QucsExporter::exportCell() → schematic_roundtrip.sch

5. Qucs → CORE mapping

QucsCORE
<Components> lineInstance (cellName = Qucs type, qucs.instName = R1, C1, …)
<Wires> labelNet name
Wire endpointsTerm positions (1 DBU = 1 Qucs pixel)
View typeViewType::Schematic

6. Sample text dump

cell "rc_lowpass"
  type schematic dbuPerMicron=1.000
  shapes=0 instances=4 nets=3
    instance -> "R" at (280,200)
    instance -> "C" at (480,200)
    net "N1" sig=signal terms=4

Limitations

  • Only schematic topology is mapped; simulation diagrams are stored but not interpreted
  • Implicit connectivity through unlabeled wire junctions uses endpoint union-find (anonymous nets N$N)
  • Qucs component libraries (.lib) are not imported yet
