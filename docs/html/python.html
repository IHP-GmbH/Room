Python API

Use ROOM from Python without knowing C++: open .room files, list cells, read shapes, convert GDS / Qucs / Xschem / OASIS, and edit designs in scripts. More…

Package:pip install ./python (from the ROOM repository)
Import:import room
CLI:room … or python -m room …
Reference:Python class index (full members)

What is in the database?

A .room file is a Database with metadata, a layer table, and cells:

Database +-- lib_name, version, generator, technology +-- layers[] -> Layer +-- cells[] -> Cell +-- contents[] -> CellContent (layout / schematic / …) +-- shapes[] / instances[] / bbox

Start at the class index, then Database, Cell / CellContent, types & enums. C++ docs are optional — the Python pages list every function you can call.

Install

pip install ./python
# editable:
pip install -e ./python[test]

On Windows use 64-bit MinGW matching 64-bit CPython (default C:\msys64\mingw64). First install builds room_c via CMake. OASIS needs zlib; check room.has_oas().

Quick start

import room

db = room.open("design.room")
print(db.cell_names())
for cell in db.cells:
    layout = cell.layout
    if layout:
        print(cell.name, "shapes", len(layout.shapes), "bbox", layout.bbox)

with room.create() as db:
    cell = db.get_or_create_cell("INVX1")
    layout = cell.ensure_content("layout")
    layout.add_rect(0, 0, 0, 100, 200)
    db.save("out.room")

CLI

room info design.room
room ls design.room
room convert chip.gds chip.room
room convert --tool qucs rc.sch rc.room --view schematic
room convert --tool xschem inv.sch inv.room --view schematic
