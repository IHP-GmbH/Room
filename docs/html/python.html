Python API

Script and inspect .room databases from Python without rebuilding C++ each time. The package wraps the same C++ core used by the importers/exporters. More…

Package:pip install ./python (from the ROOM repository)
Import:import room
CLI:room … or python -m room …
Native lib:room_c shared library (ctypes)

Install

pip install ./python
# editable:
pip install -e ./python[test]

On Windows use a 64-bit MinGW toolchain matching 64-bit CPython (default C:\msys64\mingw64). The first install builds room_c via CMake. OASIS support requires zlib (room_oas); check with room.has_oas().

Quick start

import room

db = room.open("design.room")
print(db.cell_names())
print(db.info())

with room.create() as db:
    cell = db.get_or_create_cell("INVX1")
    layout = cell.ensure_content("layout")
    layout.add_rect(0, 0, 0, 100, 200)
    db.save("out.room")

CLI

room info design.room
room info --sniff --json design.room
room ls design.room

room convert chip.gds chip.room
room convert chip.room chip.gds
room convert --tool qucs rc.sch rc.room --view schematic
room convert --tool xschem inv.sch inv.room --view schematic
room convert layout.room layout.oas          # if has_oas()

Converters

Same formats as the C++ tools, exposed on room.Database:

DirectionPythonC++ counterpart
GDS → ROOMroom.from_gds(path)GdsImporter
ROOM → GDSdb.to_gds(path)GdsExporter
Qucs → ROOMroom.from_qucs(path)QucsImporter
ROOM → Qucsdb.to_qucs(path, cell=None)QucsExporter
Xschem → ROOMroom.from_xschem(path)XschemImporter
ROOM → Xschemdb.to_xschem(path, cell=None)XschemExporter
OASIS → ROOMroom.from_oas(path)OasImporter
ROOM → OASISdb.to_oas(path)OasExporter

Module surface

room.open(path)Load a .room file.
room.create()Empty in-memory database.
room.sniff(path)Header-only metadata (see sniffRoomFile).
room.has_oas()Whether this build linked OASIS support.
db.cells / db.find_cellCell inventory.
cell.ensure_content(view)Create/get layout or schematic view.
layout.add_rect(...)Mutate geometry.
db.save(path, view=...)Write .room.

Notes

  • The Python API is a thin layer over the C++ room:: model — semantics match the C++ class docs.
  • For schematic .sch files, pass --tool qucs or --tool xschem to the CLI when auto-detect is ambiguous.
  • Source and tests live under python/ in the repository.
