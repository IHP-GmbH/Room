cdb::CellContent class

src/cell_content.h · #include "cell_content.h"

Cell data for a single view type. The viewType field distinguishes layout, schematic, symbol, or abstract. Holds a layer table and a Block with topology.

Member functions

CellContent(ViewType viewType, double dbuPerMicron = 1000.0)

Constructs view data for one cell view with an empty layer table and empty Block.

viewTypeKind of view: Layout, Schematic, Symbol, or Abstract.
dbuPerMicronCoordinate resolution: database units per micron (default 1000, matching typical GDS imports).

Example

cdb::CellContent content(cdb::ViewType::Layout, 1000.0);

content.layers().push_back({2, 0, "L2/D0", cdb::LayerPurpose::Drawing});
content.layers().push_back({3, 0, "L3/D0", cdb::LayerPurpose::Label});

cdb::Block & block = content.block();
block.shapes().emplace_back(cdb::Shape::TextData{
    {100, 100}, "TOPCELL", 1, 200});
block.recomputeBBox();
