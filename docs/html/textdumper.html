cdb::TextDumper class

utils/text_dump.h · #include "text_dump.h"

Human-readable text dump of a Database for debugging and verifying imports.

Member functions

void dump(const Database & db, std::ostream & out) const

Writes a human-readable summary of the database to an output stream.

ParameterDescription
dbDatabase to dump (typically loaded from a .cdb file or built in memory).
outDestination stream (for example std::cout or a std::stringstream).
void dumpToFile(const Database & db, const std::string & path) const

Writes the same text dump as dump() to a file.

ParameterDescription
dbDatabase to dump.
pathOutput text file path. The file is created or overwritten.

Throws: std::runtime_error if the file cannot be opened for writing.

Output format

=== CommonDB text dump ===
version: 0.1
generator: CommonDB GdsImporter
lib: gds_import
cells: 2

cell "TOP"
  type layout dbuPerMicron=1000.000 layers=3
  bbox=(0,0)-(5000,5000)
  shapes=2 instances=1 nets=0
    shape polygon layer=L1/D0 points=4
    instance -> "INV" at (2000,2000)

Example

cdb::Database db = cdb::Database::loadFromFile("design.cdb");

cdb::TextDumper dumper;
dumper.dump(db, std::cout);
dumper.dumpToFile(db, "design.txt");
