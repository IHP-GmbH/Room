Cell Class (Python)

A named design cell with one or more view bodies (CellContent).

Obtained from:db.cells, db.find_cell(name), db.get_or_create_cell(name)

Properties / methods

name -> strCell name (read-only).
contents -> list[CellContent]All stored views.
layout -> CellContent | NoneShortcut for layout view.
content(view="layout") -> CellContent | NoneFind an existing view ("layout", "schematic", …).
ensure_content(view="layout", dbu_per_micron=1000.0) -> CellContentGet or create a view.

Example

cell = db.get_or_create_cell("INVX1")
layout = cell.ensure_content("layout")
sch = cell.content("schematic")  # may be None

CellContent Class (Python)

One view of a cell: geometry (shapes), placements (instances), and bounding box. Corresponds to C++ room::CellContent + its block().

Properties

view -> ViewTypeWhich view this body is.
dbu_per_micron -> floatCoordinate scale for layout.
bbox -> BoxCached bounding box.
shapes -> list[Rect | dict]Rectangles as Rect; other kinds as {"type": "...", "index": i}.
instances -> list[Instance]Child cell placements.

Methods

add_rect(layer_id, llx, lly, urx, ury) -> intAppend a rectangle; returns shape index.
add_instance(cell_name, x=0, y=0, orient=Orient.R0, mag=1.0) -> intPlace a child cell.

add_rect(layer_id, llx, lly, urx, ury) → int

layer_id indexes into the library layer table (see db.layers). Coordinates are integer database units.

add_instance(cell_name, x=0, y=0, orient=Orient.R0, mag=1.0) → int

Adds a reference to another cell by name. The child cell should exist in the same database.

Example

layout = cell.ensure_content("layout")
layout.add_rect(layer_id=0, llx=0, lly=0, urx=100, ury=200)
layout.add_instance("FILL", x=1000, y=0)

for shape in layout.shapes:
    if isinstance(shape, room.Rect):
        print(shape.layer_id, shape.llx, shape.lly, shape.urx, shape.ury)

for inst in layout.instances:
    print(inst.cell_name, inst.x, inst.y, inst.orient)
