XschemExporter Class

Exports schematic/symbol views to native Xschem files. More…

Header:#include "xschem_exporter.h"
CMake:target_link_libraries(mytarget PRIVATE ROOM::room_utils)

Public Functions

void exportCell(db, cellName, outputPath) constOne cell/view to .sch or .sym.
std::size_t exportAll(db, outputDir) constAll cells in library directory.
warnings(), errors()Messages from last export.

Detailed Description

Uses room::xschem::exportRecords with effectiveDbuPerEditorUnit(). For Qucs-sourced views, maps component types to Xschem symbols. Extension follows CellContent::viewType() via xschem_format. See coordinate scale.

CLI: room_to_xschem.

Example

room::Database db = room::Database::loadFromFile("inv.schematic.room");
room::XschemExporter exporter;
exporter.exportCell(db, "inv", "payload/inv.sch");
