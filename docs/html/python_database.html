Detailed Description

A Database owns one library of cells. Use cells / find_cell to navigate, then open a CellContent view to see shapes and instances. You do not need the C++ API: everything listed here is available from Python.

Member documentation

classmethod create() → Database

Creates an empty database (lib_name="default", version="1.0").

classmethod open(path: str | Path) → Database

Loads a .room file. Raises RuntimeError on I/O or parse failure.

classmethod from_gds(path) → Database

Imports a GDSII layout into a new database (layout views).

classmethod from_qucs(path) → Database

Imports a Qucs .sch schematic.

classmethod from_xschem(path) → Database

Imports an Xschem .sch or .sym file.

classmethod from_oas(path) → Database

Imports OASIS. Requires a build with zlib / room_oas (room.has_oas()).

save(path, view="layout") → None

Writes the database to .room. view may be a string ("layout", "schematic", …) or ViewType.

info() → dict

Returns keys: version, generator, technology, lib_name, file_view, cell_count, cells, layer_count, summary fields.

Example

import room

with room.open("stdcells.room") as db:
    print(db.info())
    inv = db.find_cell("sg13g2_inv_1")
    if inv and inv.layout:
        print("bbox", inv.layout.bbox)
        print("rects", [s for s in inv.layout.shapes if isinstance(s, room.Rect)][:3])

with room.from_gds("chip.gds") as db:
    db.lib_name = "chip"
    db.save("chip.room")
    db.to_gds("chip_roundtrip.gds")
