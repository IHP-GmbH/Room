CORE

Open-source IC layout database on Cap'n Proto

CORE is a teaching and application API for storing layout topology (cells, layers, shapes, instances, nets). Data is serialized to a binary .core file through Cap'n Proto.

CORE is part of the IHP open-source IC design toolchain. It stores layout and schematic topology from sources such as the IHP Open Source PDK (e.g. sg13g2 GDS) or Qucs schematics. Cap'n Proto is built locally under third_party/capnp-install/ (CMake runs scripts/mkcapnp.cmd automatically on first configure). The view type (layout, schematic, symbol) is stored directly in CellContent.

Data hierarchy

Database └── Lib └── Cell[] └── CellContent[] ← viewType: layout | schematic | symbol | abstract ├── dbuPerMicron, layers └── Block ├── Shape[] ├── Instance[] └── Net[]

Quick start (VS Code)

Ctrl+Shift+B → Example: Build & Run Full Demo

Or build static libraries only: Build: Static Libraries (.a)

Quick start (command line)

cmake -S . -B build -G "MinGW Makefiles"
cmake --build build

.\build\make_sample_gds.exe testdata\sample.gds
.\build\gds_to_core.exe examples\gds_to_core\data\sg13g2_stdcell.gds out\layout.core

.\build\qucs_to_core.exe examples\qucs_to_core\data\rc_lowpass.sch out\schematic.core
