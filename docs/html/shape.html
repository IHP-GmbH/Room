core::Shape class

src/shape.h · #include "shape.h"

Layout geometry object. The kind is given by Shape::Type and the matching data struct.

enum Type

ValueData structGDS
RectRectDataBOX
PolygonPolygonDataBOUNDARY
PathPathDataPATH
TextTextDataTEXT

Member functions

explicit Shape(RectData data)

Constructs a rectangle shape (GDS BOX).

ParameterDescription
dataBounding box and layer index (layerId refers to Lib::layers()).

explicit Shape(PolygonData data)

Constructs a polygon shape (GDS BOUNDARY).

ParameterDescription
dataVertex list and layer index.

explicit Shape(PathData data)

Constructs a path shape (GDS PATH).

ParameterDescription
dataCenterline points, path width, and layer index.

explicit Shape(TextData data)

Constructs a text label shape (GDS TEXT).

ParameterDescription
dataAnchor position, string, layer index, and text height in DBU.

Type type() const

Returns which geometry kind this shape holds.

Returns: Rect, Polygon, Path, or Text.

const RectData * rect() const

Accesses rectangle data when the shape type is Rect.

Returns: Pointer to internal RectData, or nullptr if type() != Type::Rect.

const PolygonData * polygon() const

Accesses polygon data when the shape type is Polygon.

Returns: Pointer to internal PolygonData, or nullptr if the type does not match.

const PathData * path() const

Accesses path data when the shape type is Path.

Returns: Pointer to internal PathData, or nullptr if the type does not match.

const TextData * text() const

Accesses text data when the shape type is Text.

Returns: Pointer to internal TextData, or nullptr if the type does not match.

std::vector<Property> & properties()

Returns shape metadata for modification.

Returns: Mutable reference to name/value Property pairs.

const std::vector<Property> & properties() const

Returns shape metadata for read-only access.

Returns: Const reference to shape properties.

Example

// polygon
block.shapes().emplace_back(core::Shape::PolygonData{
    {{{0,0}, {1000,0}, {1000,500}, {0,500}}}, 0});

// path
block.shapes().emplace_back(core::Shape::PathData{
    {{{500,500}, {5000,5000}}}, 200, 1});

// text
block.shapes().emplace_back(core::Shape::TextData{
    {100, 100}, "label", 2, 100});

// read back
for (const core::Shape & s : block.shapes()) {
    if (s.type() == core::Shape::Type::Polygon) {
        const auto *p = s.polygon();
        // p->points, p->layerId
    }
