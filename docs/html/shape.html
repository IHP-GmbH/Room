Detailed Description

A core::Shape stores one piece of layout geometry inside a Block. The active variant is selected by type(); use the matching accessor (rect(), polygon(), …) to read payload data. Each variant carries a layerId index into the view or library LayerSpec table—not a raw GDS layer number.

Shapes may carry Property lists (for example GDS user attributes encoded as gds.prop.<attr> after import).

struct RectData { Box box; std::uint32_t layerId; }

Rectangle geometry in DBU. box uses lower-left / upper-right corners (Box).

struct PolygonData { std::vector<Point> points; std::uint32_t layerId; }

Closed polygon hull in DBU vertex order.

struct PathData { std::vector<Point> points; std::uint32_t width; std::uint32_t layerId; }

Centerline polyline; width is full path width in DBU (0 allowed).

struct TextData { Point position; std::string text; std::uint32_t layerId; std::uint32_t height; }

Text anchor, string payload, layer index, and character height in DBU.

Example

core::Block & block = layout.block();

block.shapes().emplace_back(core::Shape::PolygonData{
    {{{0,0}, {1000,0}, {1000,500}, {0,500}}}, 0});

block.shapes().emplace_back(core::Shape::PathData{
    {{{500,500}, {5000,5000}}}, 200, 1});

for (const core::Shape & shape : block.shapes()) {
    if (shape.type() == core::Shape::Type::Polygon) {
        const auto *poly = shape.polygon();
        // poly->points, poly->layerId
    }
}
