Database Class

Root object of a ROOM design. Python counterpart of C++ room::Database. Also hosts the library API (see Lib). More…

Import:import room
Factories:room.open, room.create, room.from_gds, …
C++:room::Database

Notation: names with () are methods (call them). Names without () are attributes / properties (read or assign, do not call). Example: cell.name() vs db.lib_name = "stdcells".

Detailed Description

A Database holds file metadata and one library of cells. Library operations that live on db.lib() in C++ are methods/attributes of Database in Python (see Lib).

Member documentation

Database.create() / room.create() → Database

Empty database. Default version is "1.0", lib_name is "default".

Database.open(path) / room.open(path) → Database

Loads a .room file (C++ loadFromFile).

version: str

Attribute (no call). Maps to C++ version() / setVersion. Assign with db.version = "1.0".

generator: str

Attribute. Creating tool name.

technology: str

Attribute. Technology / PDK identifier.

lib_name: str

Attribute. Library name (C++ lib().name()). Not db.name() — that would be ambiguous with cell names.

file_view: ViewType

Attribute. Primary view kind written into the file summary.

cells() → list[Cell]

Method. All cells (C++ lib().cells()). Call as db.cells().

cell_names() → list[str]

Method. Equivalent to [c.name() for c in db.cells()].

layers() → list[Layer]

Method. Shared layer table (C++ lib().layers()).

find_cell(name) → Cell | None

Method. Exact-name lookup (C++ findCell).

get_or_create_cell(name) → Cell

Method. Return existing cell or create an empty one.

add_layer(layer_num, data_type=0, name="", purpose=...) → int

Method. Append a layer; returns index usable as layer_id in add_rect.

info() → dict

Method. Convenience summary for printing / JSON.

save(path, view="layout")

Method. Write .room (C++ saveToFile).

Example

import room

with room.open("design.room") as db:
    print(db.lib_name)                 # attribute — no ()
    print(db.cell_names())             # method — with ()
    cell = db.find_cell(db.cell_names()[0])
    print(cell.name())                 # method — with ()
    print(cell.layout().bbox())
