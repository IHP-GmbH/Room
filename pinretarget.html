Detailed Description

Qucs and Xschem draw the same ROOM topology with different native symbol geometries. When QucsExporter or xschem_bridge emits wires, pin retargeting keeps wire endpoints on the visible pin centers of attached primitive symbols instead of stale LibComp anchor points.

Tolerance scales with dbuPerEditorUnit (typically 1 for Qucs-origin, 1000 for Xschem-origin views). See Coordinate scale for orientation helpers in coord_scale.h (orientFromQucsPlacement, PDK E–W → N–S compensation).
