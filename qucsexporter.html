Detailed Description

Uses stored qucs.wire lines when present for lossless round-trip. Otherwise reconstructs wires from Net terminals with pin retargeting when primitive symbols are attached. Coordinates are converted with dbuPerEditorUnit via coord_scale.

Export policy: map attached passives to native Qucs devices (res → R, capa → C, iopin → Port). Emit <Lib> only for PDK/hierarchy cells and visual title blocks (title*). Skip Xschem decorations via isQucsSchematicDecoration().
